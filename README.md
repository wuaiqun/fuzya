# 富滋雅 - 高端全屋定制网站

一个极简风格、高端的全屋定制网站，采用现代化设计理念。

## 特点

- 🎨 **极简设计** - 简洁优雅的界面，突出内容本身
- 📱 **响应式布局** - 完美适配各种设备尺寸
- ⚡ **流畅动画** - 精心设计的交互动画，提升用户体验
- 🎯 **高端定位** - 专业的视觉呈现，彰显品牌价值

## 功能模块

### 1. 首页英雄区
- 大标题展示品牌理念
- 醒目的行动号召按钮
- 优雅的滚动指示器

### 2. 服务展示
- 全屋设计
- 衣柜定制
- 橱柜定制
- 书房定制

### 3. 案例展示
- 网格布局展示精选案例
- 悬停效果增强交互
- 渐变色彩作为占位图

### 4. 定制流程
- 4步清晰流程展示
- 圆形数字标识
- 悬停动画效果

### 5. 预约咨询
- 简洁的表单设计
- 实时表单验证
- 提交成功反馈

## 技术栈

- **HTML5** - 语义化标签
- **CSS3** - 现代化样式，Grid & Flexbox 布局
- **原生 JavaScript** - 无依赖，轻量级交互

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器：
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 使用 Node.js
   npx serve
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 设计特色

### 配色方案
- 主色：深黑 (#1a1a1a)
- 辅助色：浅灰 (#f5f5f5)
- 强调色：金色 (#d4af37)

### 字体
- 系统默认字体栈，优先使用苹方、微软雅黑等中文字体
- 大量留白，提升阅读体验

### 动画效果
- 页面滚动时的元素淡入
- 导航栏智能隐藏/显示
- 卡片悬停效果
- 平滑滚动

## 自定义修改

### 修改品牌名称
在 `index.html` 中搜索 "富滋雅" 并替换为您的品牌名称。

### 修改配色
在 `styles.css` 的 `:root` 部分修改 CSS 变量：
```css
:root {
    --primary-color: #1a1a1a;
    --accent-color: #d4af37;
    /* 其他颜色变量 */
}
```

### 添加真实图片
将案例展示区的渐变背景替换为真实图片：
```html
<div class="portfolio-image" style="background-image: url('images/case1.jpg');"></div>
```
